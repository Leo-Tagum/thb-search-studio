# Phase 6 — Measurement & Learning

## Goal
Show whether published changes helped qualified seller leads. Organic clicks, leads, AI citations, mentions and referrals stay separate, and every figure is labelled measured, estimated or unknown. Monthly refresh proposals feed back into the opportunity queue.

## Read first
- Design `docs/superpowers/specs/2026-10-10-thb-search-studio-design.md` — §2 Anti-goals, §5 Ingestion (GSC, GA4, lead CSV), §7 Calls (lead data via CSV).
- Blueprint `THB_Search_Growth_and_Content_Intelligence_System_v2_0.md` — §2 Measurement hierarchy, §9 AI visibility reporting paragraph, §11 Dashboard + Published Content & Refreshes, §13 Phase 6, §16 Reporting Dashboard and KPIs (all).
- Phase 5 handoff in `phase-5-pilots.md`, and the Phase 0 handoff (available GA4 conversion events).

## Depends on
Phase 5 **DONE**. There must be publication events with prior versions recorded, and GSC/GA4 ingestion must be working.

## Tasks
**To be detailed at the start of this phase**, using the Phase 5 handoff. The session's first job is to write numbered small tasks here, each with a check, and get Leo's OK before building.

Expected areas (outline only):
- Baseline vs comparison windows for each published page.
- GA4 conversion pull.
- Lead CSV import with an attribution confidence field.
- A manual AI observation log recording platform, prompt, locale, date, method, URL and repeatability.
- The executive dashboard: releases vs the target of 3, decision counts, blocks, cost per release, cycle time.
- Monthly refresh proposals into the opportunity queue.

## Out of scope
- Automated rank or AI-visibility scraping.
- Claims that a change caused lead growth. Correlation is labelled as correlation.
- Any automatic change to live URLs.

- [ ] Every figure shows measured, estimated or unknown, plus data freshness
- [ ] Refresh proposals land in the opportunity queue as recommendations only
- [ ] Blueprint §19 Definition of Done reviewed and remaining items listed
